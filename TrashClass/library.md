# Library of Related Works  
### *Books, theories, models, and media connected to the TrashClass tetralogy*

This library gathers sources across multiple paradigms — scientific, spiritual, psychological, philosophical, and artistic — that illuminate the themes explored in the four parts and the Afterword.  
Some works reinforce each other; others contradict each other.  
This is intentional: understanding a system requires seeing **the whole landscape**, not a single doctrine.
